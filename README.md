# Pokédex

Aplicação web desenvolvida com **Python e Flask**, integrada à **PokeAPI**, permitindo consultar informações de Pokémon através de uma interface inspirada em uma Pokédex.

## Sobre o projeto

O projeto foi desenvolvido para praticar o desenvolvimento de aplicações web utilizando Flask, integração com APIs externas, banco de dados e operações CRUD.

A aplicação permite consultar informações de Pokémon através da PokeAPI, além de possuir funcionalidades para cadastro, edição e exclusão de Pokémon armazenados no banco de dados.

## Funcionalidades

- 🔎 Consulta de Pokémon por nome ou número
- 📋 Exibição de informações do Pokémon
- 🖼️ Exibição da imagem oficial do Pokémon
- ⚡ Visualização dos tipos
- 📏 Exibição de altura e peso
- ⭐ Visualização de habilidades
- 📊 Exibição dos atributos base
- 📄 Paginação dos resultados
- ➕ Cadastro de Pokémon
- ✏️ Edição de Pokémon
- 🗑️ Exclusão de Pokémon
- 🖼️ Upload e gerenciamento de imagens

## Tecnologias

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- PokeAPI

## API utilizada

O projeto utiliza a **PokeAPI** para obter informações sobre os Pokémon.

As informações são consumidas através de requisições HTTP e processadas pela aplicação Flask.
